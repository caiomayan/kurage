# Contributing to Kurage / Contribuindo com o Kurage

Kurage is a proprietary product under active development. The canonical
repository is private and does not accept unsolicited external pull requests.
This policy protects software-registration evidence, confidential product work,
and a clear chain of title.

Authorized contributors must, before making changes:

1. have written repository access and an applicable confidentiality and
   intellectual-property agreement;
2. create a focused branch and reference the approved work item;
3. never commit secrets, customer data, production exports or unlicensed assets;
4. update the relevant Portuguese and English documentation together;
5. run the component tests, lint, build and secret/dependency scans; and
6. use a reviewed pull request with signed or otherwise attributable commits.

Contributions to `server/plugins` are published under its separate MIT license.
Contribution to that directory does not change the proprietary license of the
rest of the repository.

---

O Kurage é um produto proprietário em desenvolvimento. O repositório canônico é
privado e não aceita pull requests externos não solicitados. Contribuidores
autorizados devem possuir acordo escrito de confidencialidade e propriedade
intelectual, trabalhar em branch vinculada a uma demanda aprovada, nunca enviar
segredos/dados reais/ativos sem licença, manter a documentação PT/EN sincronizada
e passar por testes e revisão. Os plugins de `server/plugins` permanecem sob MIT.
